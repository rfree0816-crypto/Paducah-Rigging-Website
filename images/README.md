# Product photos go here

Not committed yet — none have been sourced. `index.html` falls back to
built-in SVG line art when a file is missing, so the site works without
this folder being populated.

## Naming, in lookup order

1. `<unique part #>.jpg` — e.g. `PH-00123.jpg`
2. `<category>-<group>.jpg` — e.g. `shackles-domestic.jpg`
3. `<category>.jpg` — e.g. `shackles.jpg`

First one that exists wins.

See `../phatrigging-photo-shotlist.csv` for the full list of filenames
needed (47 cover every item: 18 category-level, 29 group-level) plus
optional per-item shots. Legitimate sources are the Crosby / CM /
Harrington / Peerless dealer media libraries, or photographing the actual
stock — not random web images.
